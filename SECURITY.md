# Security Policy

This tap distributes the `shield` formula, which installs a binary that runs as
a git pre-commit hook on developer machines. Integrity of the formula (download
URLs and SHA256 checksums) matters.

`Formula/shield.rb` is generated by goreleaser from the
[shield-go](https://github.com/chinmaymjog/shield-go) release process. Pull
requests that hand-edit the formula (URLs, checksums) will not be accepted.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/homebrew-shield/security/advisories/new>

If you believe a published formula points at a tampered artifact, report it
immediately the same way.

## Supported versions

Only the latest release of `shield` receives security fixes.
